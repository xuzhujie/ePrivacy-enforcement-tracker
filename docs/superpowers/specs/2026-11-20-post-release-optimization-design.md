# ePrivacy Tracker 上线后优化设计

## Intent

让已上线的 ePrivacy Tracker 在证据口径、来源新鲜度、筛选解释性、键盘可用性和构建复现性上达到可持续维护的状态。优化面向研究人员、政策分析人员和维护者，重点是让读者能区分“官方证据已核验”和“来源 URL 最近可访问”。

## Goals

- 将人工证据状态与自动来源可达性分离，并在看板中同时呈现。
- 在总览、案件、时间线和来源视图之间保留筛选时，明确显示当前筛选范围。
- 实现顶部 `⌘/Ctrl + K` 搜索快捷键，并提升证据抽屉和案件行的键盘/屏幕阅读器语义。
- 让机构、国家和其他筛选项按当前语言显示，同时保留稳定筛选值。
- 通过 `package-lock.json` 和 `npm ci` 固定 CI 安装结果。
- 更新历史 QA 文档，使当前数据快照与上线状态不再产生误导。
- 保持 App SDK 的证据边界：没有官方明确 SDK 表述时，不新增推断性案件。

## Non-goals

- 不把 HTTP 403 自动改成证据失效或案件排除。
- 不引入后端数据库、爬虫服务、登录系统或第三方监测平台。
- 不改变现有 ePrivacy/GDPR 金额计入口径，不重新拆分未被官方原文拆分的金额。
- 不为了填充 App SDK 标签而添加缺少直接官方依据的案件。

## Anti-goals

- 不把“来源可达”当成“法律依据已核验”。
- 不让总览中的筛选后金额看起来像全库总额。
- 不把静态站点改造成需要运行时服务才能打开的应用。

## Constraints

- 继续使用现有 React + Vite + TypeScript 静态站点。
- 保留现有双语数据模型和 GitHub Pages 发布方式。
- 所有行为变化先以失败测试固定，再实现最小改动。
- 初始优化基线为 20 案件、30 条来源和 3 条人工复核队列；后续官方 SOLOCAL 结案证据使当前登记库变为 21 案件、34 条案件—来源记录、32 条去重来源，UI/CI 优化不能改变法律计入口径。

## Approaches considered

### A. 只修 UI 文案和本地字段（不采用）

实现最快，但来源巡检仍停留在 Actions artifact，线上看板无法显示最近可达性；会继续混淆静态证据状态和动态 URL 状态。

### B. 引入后端或第三方来源监测服务（不采用）

能提供实时状态，但超出当前静态站点范围，增加凭证、部署和维护成本，也不适合当前来源数量。

### C. 静态来源状态快照 + 工作流更新（采用）

增加稳定的来源状态快照 schema。Pages 构建把当前快照放入 `public/source-status.json`，看板以降级方式读取；来源巡检保留完整 artifact，并在运行后更新快照，使下一次 Pages 发布能显示最近巡检结果。人工证据状态仍由案件数据独立控制。

## Design decisions

1. `CaseSource.verificationStatus` 继续表示人工证据核验，不改名、不复用。
2. 新增 `SourceStatusSnapshot` 表示一次自动 URL 检查，至少包含 `checkedAt`、总数、`okCount`、`attentionCount`、`blockingCount` 和每 URL 结果。
3. 线上总览显示来源登记总数、最近可访问数和待复核数；不再把登记总数标为“已核验来源”。
4. 当前筛选继续跨视图保留，但在页面标题区显示筛选摘要和清除入口；主题计数标明属于当前筛选范围。
5. 搜索快捷键同时支持 macOS `Meta+K` 和 Windows/Linux `Ctrl+K`，不覆盖输入、文本域和可编辑元素中的原生行为。
6. 证据抽屉采用可访问的 dialog 语义，打开时聚焦关闭按钮，Escape 关闭并将焦点返回触发案件行。
7. 机构和国家筛选使用稳定英文值作为内部值，显示文本根据 `language` 切换。
8. App SDK 仍保持零计数，直到新增案件满足官方明确提及 SDK 的证据要求。

## Acceptance criteria

- `npm run data:check`, `npm test`, `npm run lint`, `npm run build` 全部通过。
- source status helper 能区分 `ok`、`needs_review` 和 `unreachable`，快照缺失或异常时看板仍可正常打开。
- 总览不再把全部来源标记成已核验；能显示最近自动巡检日期和状态摘要。
- 任何非默认筛选跨视图时，读者能看到当前筛选范围并能一键清除。
- `Meta/Ctrl+K` 聚焦搜索；抽屉支持 Escape 关闭和焦点返回；案件行可用键盘操作。
- 中文界面的机构、国家筛选显示中文，英文界面显示英文，过滤结果保持一致。
- CI 使用 lockfile 安装依赖；来源巡检仍保留完整 artifact，并更新可供 Pages 使用的状态快照。
- QA ledger 的当前数据数字与 `npm run data:check` 一致。
